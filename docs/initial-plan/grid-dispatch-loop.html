Data

Two public UK energy APIs, no signup, no key — verified live while scoping this. Grid carbon intensity from National Grid ESO; half-hourly wholesale price from Octopus's Agile tariff. rules.py isn't an API — three plain constants checked in code, not by a model.

Tools

Thin wrappers, nothing clever. Each one fetches, parses, and returns; the agents decide what to do with the result. Responses are cached to disk after the first call, so a rehearsal run doesn't re-hit either API.

Agents

The only two LLM calls in the system. Analyst proposes a two-hour window and explains its reasoning. Reviewer checks the proposal against rules.py and can send it back — once. This loop is the actual demo.

Output

Reviewer's approval prints a short recommendation to the terminal and writes a one-page markdown brief — the same handover a human ops analyst would give at shift change.

Deliberately left out

  • Battery state-of-charge model — real engineering, zero agent content
  • More than one reject/replan round — one shows the mechanism just as well
  • A dashboard UI — a printed trace is easier to narrate live
  • A third data source — two signals is enough to show a genuine trade-off
